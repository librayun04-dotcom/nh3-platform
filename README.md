# 氨电联产 AGC 调度控制系统（nh3-platform）

基于自研离散 PPO 深度强化学习的氨电联产综合能源系统 **AGC 调度控制终端**。
系统定位为火电-氨电联产厂站的在运调控软件：策略内核持续滚动决策，每 15 分钟下发一次
电解槽功率指令，前端以 SCADA 风格呈现单线图潮流、机组状态、遥测曲线与事件告警。

> 主论文与完整实验见主仓库：https://github.com/librayun04-dotcom/nh3

## 运行界面（四个业务页面）

| 页面 | 内容 |
|------|------|
| 调度总览 | 220kV 单线图（潮流动画 + 实时遥测）、AGC 实时指令面板（档位/MW/CMD 编号）、六项核心遥测、机组状态灯与负载条、实时事件流 |
| 实时趋势 | 全时步功率平衡（支持缩放）、累计氢氨产量、新能源利用率与考核线 |
| 典型日复盘 | 四个典型气象日由在运策略内核全天推演，与无电解槽/恒定功率/贪心消纳三种参照方式对照，用于运行分析与岗位培训 |
| 事件记录 | 全量事件流：AGC 指令调整、弃电起止、日结算完成、通信状态等，按类别过滤 |

系统行为特征：

- **自动连续运行**——打开页面即投入运行，一个运行日结算完成后自动进入下一天，无需人工干预
- **事件驱动告警**——档位增减载、弃电出现/恢复、通信中断等自动生成带级别的事件记录并累加告警计数
- **通信看护**——WebSocket 断线自动重连，中断期间状态栏转红提示

## 快速开始

```bash
pip install -r requirements.txt      # Python >= 3.10
python -m uvicorn server.main:app --host 127.0.0.1 --port 8000
# 或 Windows 直接双击 start.bat；浏览器打开 http://127.0.0.1:8000
```

仓库自带 100 万步已训练策略内核（`output/data/ppo_agent.pt`），克隆即可投运。

```
nh3-platform/
├── config.py                  # 全局配置（装机/经济参数/PPO超参）
├── server/
│   ├── main.py                # FastAPI 后端（仿真会话/复盘/模型管理 API）
│   └── web/index.html         # SCADA 风格调调度终端前端
├── src/
│   ├── agents/                # 自研离散 PPO + 基线策略
│   └── models/                # AGC环境/向量化环境/电解槽/火电/风光/氨储模型
├── samples/                   # 典型日示例曲线
└── output/data/ppo_agent.pt   # 在运策略内核（100万步）
```

## API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/models` | 策略内核清单 |
| GET | `/api/cases` | 典型日列表 |
| POST | `/api/run_case` | 典型日全天推演（表单 `case_id`） |
| POST | `/api/predict` | 曲线推理（工程接口，表单 `file`, 可选 `model`） |
| POST | `/api/train/start` / `/stop` / `GET /stream` | 内核再训练（工程接口，SSE 进度） |
| WS | `/ws/simulate` | 实时调度会话（start/pause/resume/step/reset） |

## MDP 建模要点

- **状态（12 维）**：光伏/风电/负荷标幺、时刻周期编码、电解槽与火电出力、弃电惩罚因子、
  分时电价、当前弃电潜力、未来 4h 弃电预测、火电爬坡余量
- **动作（11 档）**：电解槽功率 0%~100%，贴合真实 AGC 档位式下发模式
- **奖励**：分级氢价值 + 氨价值 + 副产氧 + 调峰收益 − 火电燃料成本 − 外购电 −
  弃电惩罚 − 缺电惩罚 − 制氨加热成本（元 → 万元缩放）
