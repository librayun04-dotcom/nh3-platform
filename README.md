# 氨电联产 AGC 智能调度平台（nh3-platform）

基于自研离散 PPO 深度强化学习的氨电联产综合能源系统 **AGC 调度控制终端**。
系统定位为火电-氨电联产厂站的在运调控软件：后台常驻仿真引擎持续滚动决策，每 15 分钟下发一次
电解槽功率指令；前端为 SCADA 风格调控制台，呈现单线图潮流、机组状态、遥测曲线与事件告警。

> 主论文与完整实验见主仓库：https://github.com/librayun04-dotcom/nh3

## 双击启动（推荐）

**环境**：Windows 10/11 + Python 3.10+（安装时勾选 *Add to PATH*）。

1. 下载本仓库：绿色按钮 **Code → Download ZIP** 解压，或 `git clone`
2. 进入目录，**双击 `start.bat`**
3. 浏览器自动打开 `http://127.0.0.1:8000`，即进入调度控制台

- 首次运行自动安装依赖（含 CPU 版 PyTorch 约 200 MB，需联网），之后完全离线可用
- 策略权重 `output/data/ppo_agent.pt` 已随仓库附带，克隆即可投运
- 关闭黑色控制台窗口即停止后台引擎
- Linux / macOS：`./start.sh`

## 打包为 exe（免 Python 分发）

可将平台打包成独立 exe，拷贝到任何 Windows x64 机器双击即用、无需安装 Python：

1. 在装有 Python 的机器上双击 **`build_exe.bat`**（自动安装 PyInstaller 与运行依赖）
2. 产物：`dist\氨电联产AGC调度平台\氨电联产AGC调度平台.exe`
3. 将整个 `氨电联产AGC调度平台` 文件夹拷贝到目标机，**双击其中的 exe** 即启动

| 事项 | 说明 |
|------|------|
| 体积 | 约 1 GB（内含 PyTorch CPU 推理运行时） |
| 首次启动 | 解包到临时目录需数秒，之后正常 |
| 网络 | 完全离线，仅监听本机 127.0.0.1 |
| 打包配置 | `nh3_platform.spec`（数据文件与隐藏导入均已声明） |

## 运行界面（四个业务页面）

| 页面 | 内容 |
|------|------|
| 调度总览 | 220kV 单线图（潮流动画 + 实时遥测）、调度策略选择器、AGC 实时指令面板、六项核心遥测、机组状态灯、实时事件流 |
| 实时趋势 | 全时步功率平衡（可缩放）、跨日连续累计氢氨产量、新能源消纳率与 90% 考核线 |
| 典型日复盘 | 四个典型气象日按所选策略全天推演，与无电解槽/恒定功率/贪心消纳三种参照对照 |
| 事件记录 | 全量事件流按类别过滤；支持确认全部警告、删除警告记录、清空记录 |

### 调度策略（运行中热切换）

总览页下拉框可在四种策略间即时切换（保留当日累计状态，下一时步生效）：

| 策略 | 类型 | 行为 |
|------|------|------|
| PPO 智能调度 | 强化学习内核 | 训练策略网络滚动决策（默认） |
| 贪心消纳 | 规则 | 电解槽功率 = 当前弃电潜力 |
| 恒定功率 60% | 规则 | 固定出力，无调峰意识 |
| 电解槽停运 | 参照 | 功率为零的纯弃电基准 |

典型日复盘页同样提供策略选择，按所选策略推演并生成对照图。

## 系统行为特征

- **常驻引擎**——仿真在后端全局引擎中连续滚动，页面刷新/关闭不影响运行；重新打开自动同步当日历史曲线
- **多端一致**——步长调整与策略切换作用于全厂引擎，多开页面看到同一台"机组"
- **跨日连续曲线**——趋势图保留最近 3 个运行日，日界断线不清屏；当日 KPI 独立结算归零
- **警告语义**——右上角计数只累计越限/警告，事项与正常流转静默入列表；支持一键确认/删除/清空
- **通信看护**——WebSocket 断线自动重连，中断期间状态栏转红提示

## API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/models` | 策略内核清单 |
| GET | `/api/cases` | 典型日列表 |
| POST | `/api/run_case` | 典型日全天推演（表单 `case_id`，可选 `strategy`） |
| POST | `/api/predict` | 曲线推理（工程接口，表单 `file`, 可选 `model`） |
| POST | `/api/train/start` / `/stop` / `GET /stream` | 内核再训练（工程接口，SSE 进度） |
| WS | `/ws/simulate` | 订阅常驻引擎：`hello`(含历史回放)/`step`/`day`/`day_done`/`paced`/`strategy` |

## MDP 建模要点

- **状态（12 维）**：光伏/风电/负荷标幺、时刻周期编码、电解槽与火电出力、弃电惩罚因子、
  分时电价、当前弃电潜力、未来 4h 弃电预测、火电爬坡余量
- **动作（11 档）**：电解槽功率 0%~100%，贴合真实 AGC 档位式下发模式；
  推理侧启用动作掩码（峰时无过剩功率禁止高档位），与训练口径一致
- **奖励**：分级氢价值 + 氨价值 + 副产氧 + 调峰收益 − 火电燃料成本 − 外购电 −
  弃电惩罚 − 缺电惩罚 − 制氨加热成本（元 → 万元缩放）
